# آموزش کاربری هدست واقعیت مجازی — نسخه‌ی نصب‌شدنی برای Meta Quest 2

محیط: **مرکز منابع یادگیری**
اداره آموزش و تعالی منابع انسانی شرکت پالایش نفت اصفهان

این پروژه با موتور **Godot 4.3** ساخته شده و از OpenXR برای اجرا روی کوئست ۲
استفاده می‌کند. با هر push به شاخه‌ی `main`، یک workflow در GitHub Actions
به‌صورت خودکار فایل APK را می‌سازد و به‌عنوان Artifact قابل دانلود می‌گذارد.

## محتوای آموزش

این اپ کاربر رو قدم‌به‌قدم با اجزای دسته‌ی کوئست ۲ آشنا می‌کنه، هر مرحله
با یه تمرین واقعی تأیید می‌شه:

1. دکمه‌ی ماشه (Trigger) — نشونه‌گیری و شلیک به یه هدف نورانی
2. دکمه‌ی گریپ (Grip)
3. دسته‌ی آنالوگ (Thumbstick) — هر چهار جهت
4. دکمه‌های A / B / X / Y
5. دکمه‌ی منو (Menu)
6. تله‌پورت — نشونه‌گیری و پرش به یه نقطه‌ی مشخص
7. حرکت نرم (Smooth Locomotion) — عبور از یه دروازه با هل‌دادن دسته‌ی آنالوگ

بعد از پایان آموزش، کاربر می‌تونه آزادانه با تله‌پورت و حرکت نرم توی محیط
حرکت کنه.


## راه‌اندازی اولیه (یک‌بار)

1. یک ریپازیتوری خالی در گیت‌هاب بسازید.
2. تمام فایل‌های این پوشه را داخل آن push کنید:
   ```bash
   git init
   git add .
   git commit -m "کارگاه کابینت‌سازی VR"
   git branch -M main
   git remote add origin <آدرس-ریپازیتوری-شما>
   git push -u origin main
   ```
3. به تب **Actions** در گیت‌هاب بروید. workflow با نام
   «Build Quest 2 APK» به‌طور خودکار اجرا می‌شود (چند دقیقه طول می‌کشد).
4. بعد از پایان اجرا، روی همان اجرا (run) کلیک کنید و از پایین صفحه،
   فایل ZIP به نام `cabinet-workshop-quest2-apk` را دانلود کنید. داخلش
   فایل `.apk` است.

## نصب روی کوئست ۲

1. حالت Developer Mode را روی هدست خود در اپ Meta Quest (روی گوشی) فعال کنید.
2. هدست را با کابل به کامپیوتر وصل کنید و اجازه‌ی دسترسی USB را در هدست تأیید کنید.
3. با یکی از این روش‌ها APK را نصب کنید:
   - **SideQuest**: فایل apk را باز کرده و «Install APK» را بزنید (ساده‌ترین روش).
   - **ADB**: در ترمینال بزنید: `adb install cabinet-workshop.apk`
4. اپ با نام «Cabinet Workshop VR» زیر بخش «Unknown Sources» در کتابخانه‌ی
   هدست شما ظاهر می‌شود.

## اگر ساخت APK در گیت‌هاب اکشن fail شد

کلیدهای دقیق export_presets.cfg گاهی بین نسخه‌های مختلف Godot کمی تغییر
می‌کنند. اگر لاگ اکشن خطای «Invalid export option» یا مشابه داد:

1. Godot 4.3 را روی سیستم خودتان نصب کنید (رایگان، از godotengine.org).
2. همین پوشه را با آن باز کنید.
3. از منو: `Project → Export...` — Godot به‌طور خودکار فایل
   `export_presets.cfg` را با کلیدهای درستِ نسخه‌ی نصب‌شده بازسازی می‌کند.
4. تغییرات را commit و push کنید — از این به بعد، اکشن بدون مشکل build می‌کند.

## ساختار پروژه

- `project.godot` — تنظیمات اصلی، فعال‌سازی OpenXR
- `export_presets.cfg` — پیکربندی خروجی اندروید/کوئست
- `scenes/main.tscn` + `scenes/main.gd` — منطق کارگاه: برش، سوراخ‌کاری،
  پیچ‌کاری، مونتاژ کابینت و نصب روی دیوار
- `scripts/xr_init.gd` — راه‌اندازی خودکار OpenXR هنگام اجرا
- `.github/workflows/build-apk.yml` — پایپ‌لاین ساخت APK

## چگونگی تعامل در اپ

با اشاره‌گر دسته به تکه‌ی درخشان روی میز کار نشانه بروید و ماشه را بزنید؛
تکه به‌ترتیب برش می‌خورد و در جای خودش در کابینت می‌نشیند. بعد از تکمیل
همه‌ی تکه‌ها، دیوار خانه ظاهر می‌شود — به نقطه‌ی درخشان روی دیوار نشانه
بروید و ماشه را بزنید تا کابینت نصب شود.
